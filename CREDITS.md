# Credits

The in-game Credits window (the Credits button on the title screen, or the C key) lists the same things. `scenes/screens/credits.tscn`
holds the list; a test keeps every link of it in this file.

## The game

Blue Archive Fighting Game (Tentative) is a fan project. It is unofficial and has no connection with NEXON Games or Yostar.

## Tools
